# AGENTS.md

This repository is a Copier template. `CLAUDE.md` is a link to this file.

## Rules

1. Change the template only in `template/`. Copier copies only that folder.
2. A file that needs a Copier variable gets the suffix `.jinja`. All other
   files are copied as they are.
3. Before you report done, `tests/test_template.sh` must pass.
4. Record each decision about the seed as an ADR in `template/docs/adr/`.
   Each generated project gets the ADRs.
